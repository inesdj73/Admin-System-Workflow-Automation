# 📌 [Project Title: e.g., Student Keycard & Asset Tracking System]

> **Category:** Admin Operations / Data Automation / Workflow Optimization  
> **Tech Stack:** Excel VBA, Power Query, Google Sheets DB, Notion API  

---

## 1. The Problem (The Bottleneck)
* **Context:** In private educational institutions, front-desk staff frequently face admin chaos due to manual tracking.
* **Pain Points:**
  * **Time Loss:** Staff spent 10+ hours/week manually checking paper logs and loose spreadsheets.
  * **Data Fragmentation:** Student info and asset statuses (e.g., keycards, files) were scattered across unorganized local folders.
  * **Human Error:** High risk of keycard loss and miscommunication during shift changes.

---

## 2. The Solution (The Tool & Workflow)
We designed a standardized, automated data management template to centralize administrative workflows.

* **Single Source of Truth:** Consolidated scattered logs into a structured relational database.
* **Automated Data Processing:** Implemented Excel/Google Sheets automation to streamline check-in/out and asset tracking.
* **Standard Operating Procedure (SOP):** Created a step-by-step operational guide so any staff member can run the system with zero training lag.

---

## 3. The Impact (Results & Efficiency)
* **⏱️ 80% Time Reduction:** Reduced daily tracking admin from 2 hours to 15 minutes.
* **📂 Zero Loss Rate:** Eliminating manual paper logs resulted in 100% accurate asset accountability.
* **⚡ Seamless Shift Transitions:** Allowed new and existing staff to handle inquiries without relying on key personnel memory.
